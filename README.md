# ShowMyPhoto SEO Resources

Open SEO, GEO, AEO, and AI-search resources for [ShowMyPhoto](https://showmyphoto.com), an AI-powered event photo-sharing platform for photographers.

## What's included

- `llms.txt` — concise information for AI/search crawlers
- `llms-full.txt` — expanded product and feature information
- `seo-checklist.md` — technical and content SEO checklist
- `schema/organization.json` — Organization structured-data example
- `schema/software-application.json` — SoftwareApplication structured-data example
- `robots.txt.example` — robots.txt example
- `sitemap.xml.example` — sitemap example

## About ShowMyPhoto

ShowMyPhoto helps event photographers share large event galleries and lets guests find photos using AI face recognition or selfie search.

Website: https://showmyphoto.com
Blog: https://showmyphoto.com/blog/
