# ShowMyPhoto SEO Checklist

## Technical SEO

- [ ] Keep one canonical URL per indexable page.
- [ ] Ensure important pages return HTTP 200.
- [ ] Do not send `noindex` directives on the XML sitemap.
- [ ] Keep robots.txt accessible.
- [ ] Submit the XML sitemap in Google Search Console and Bing Webmaster Tools.
- [ ] Check canonical tags.
- [ ] Check hreflang if multiple language/region pages exist.
- [ ] Remove accidental `noindex` from production pages.
- [ ] Keep Core Web Vitals under review.
- [ ] Compress and properly size images.
- [ ] Avoid render-blocking resources where practical.

## Content

- [ ] Create dedicated pages for important search intents.
- [ ] Use descriptive titles and meta descriptions.
- [ ] Answer common photographer questions directly.
- [ ] Add internal links between feature, use-case, pricing, FAQ, and blog pages.
- [ ] Avoid thin or near-duplicate pages.
- [ ] Keep comparison content factual and independently verifiable.

## Structured data

- [ ] Organization
- [ ] SoftwareApplication where applicable
- [ ] WebSite
- [ ] BreadcrumbList on hierarchical pages
- [ ] FAQPage only where the FAQ is visible on the page and eligible under current search guidelines

## AI / GEO / AEO

- [ ] Publish concise product facts in crawlable HTML.
- [ ] Maintain `llms.txt` as a supplemental resource.
- [ ] Maintain consistent product naming across official profiles.
- [ ] Make feature and use-case pages independently understandable.
- [ ] Use clear headings and question-based sections.

## Off-page

- [ ] Earn relevant editorial links.
- [ ] Publish genuinely useful open-source resources.
- [ ] Build partnerships with photography communities and software directories.
- [ ] Avoid automated, low-quality backlink networks or mass-generated submissions.
